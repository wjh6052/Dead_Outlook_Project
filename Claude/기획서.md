# Dead Outlook — 게임 기획서

> 프로젝트 좀보이드(Project Zomboid)를 기반으로 한 3D 오픈월드 좀비 생존 게임

---

## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 장르 | 3D 오픈월드 좀비 생존 |
| 시점 | 3인칭 (TPS) |
| 플랫폼 | PC (Steam) |
| 플레이 | 싱글플레이어 + 멀티플레이어 |
| 엔진 | Unity (URP) |

---

## 2. 핵심 컨셉

좀비가 창궐한 세계에서 살아남는다.  
단순한 전투가 아닌 **생존 그 자체**가 목표.  
혼자 또는 협력해서 거점을 구축하고, 자원을 모으고, 점점 강해지는 위협에 맞선다.


---

## 3. 생존 시스템

### 3-1. 스탯 (Status)
| 스탯 | 설명 |
|------|------|
| 체력 (Health) | 0이 되면 사망 |
| 배고픔 (Hunger) | 시간이 지날수록 증가, 방치 시 체력 감소 |
| 목마름 (Thirst) | 배고픔보다 빠르게 증가 |
| 피로 (Fatigue) | 활동량에 따라 증가, 수면으로 회복 |
| 체온 (Temperature) | 환경/날씨에 따라 변동, 극단값 시 패널티 |
| 스트레스 (Stress) | 좀비 목격, 부상 등으로 증가 |
| 질병 (Illness) | 감염/오염된 음식/부상 방치 시 발생 |

### 3-2. 수면
- 수면을 취하지 않으면 피로 누적 → 시야 흐림, 이동속도 감소
- 안전한 장소(거점 내 침대)에서 자면 회복량 증가

### 3-3. 부상
- 출혈, 골절, 찰과상 등 부위별 부상 처리
- 적절한 치료 아이템 사용 필요 (붕대, 소독약, 부목 등)
- 좀비에게 물리면 감염 진행 (치료 불가 — 사망 또는 전환)

---

## 4. 전투 시스템

### 4-1. 기본 전투
- TPS 기반 근접/원거리 전투
- 근접 무기: 타격감 및 스태미나 소모
- 원거리 무기: 탄약 관리, 소음 발생 → 주변 좀비 유인

### 4-2. 좀비 AI
- 시각/청각/후각으로 플레이어 탐지
- 무리 형성 — 소음 발생 시 군집 이동
- 달리는 좀비 / 걷는 좀비 / 특수 좀비 (추후 확장 예정)

### 4-3. 전투 원칙
- 1:1은 관리 가능, 다수는 위험 — 정면 충돌보다 회피/유인 전략 장려
- 총기는 강력하지만 소음으로 인한 리스크 존재

---

## 5. 건설 / 거점 구축 시스템

### 5-1. 기본 건설
- 자원(목재, 금속, 콘크리트 등) 수집 후 건축
- 벽, 바리케이드, 문, 창문, 바닥 등 배치 가능
- 기존 건물을 거점으로 개조 가능

### 5-2. 거점 방어
- 좀비의 거점 공격 대응 (문 파괴, 바리케이드 돌파)
- 함정 설치 (스파이크, 소음 유인 장치 등)
- 전력 시스템 — 발전기로 조명/전기장치 가동

### 5-3. 시설
| 시설 | 기능 |
|------|------|
| 침대 | 수면 및 체력 회복 |
| 작업대 | 크래프팅 가능 아이템 확장 |
| 화덕/스토브 | 음식 조리 |
| 저장 창고 | 아이템 보관 |
| 발전기 | 전력 공급 |

---

## 6. 제작 (크래프팅) 시스템

- 인벤토리 내 아이템 조합으로 제작
- 작업대 등 시설 근처에서만 가능한 고급 제작 존재
- 스킬 레벨에 따라 제작 가능 항목 확장

### 제작 카테고리 (초기)
| 카테고리 | 예시 |
|----------|------|
| 무기 | 못 박힌 야구방망이, 화염병 |
| 의약품 | 붕대, 소독된 거즈 |
| 음식 | 조리된 식량, 통조림 가공 |
| 건축 자재 | 목판자, 금속 프레임 |
| 도구 | 손전등, 배낭 개조 |

---

## 7. 멀티플레이어

- 협동 생존 중심 (PvE 기본)
- 동일 서버 내 PvP 옵션 (서버 설정)
- 거점 공유 및 역할 분담 플레이 유도
- 플레이어 사망 시 아이템 드롭 (서버 설정 가능)

### 7-1. 네트워크 구조

| 항목 | 내용 |
|------|------|
| 라이브러리 | Mirror (Unity 오픈소스 네트워크) |
| 방식 | Host 방식 (방장 PC = 서버 + 클라이언트) |
| 추후 확장 | 전용 서버(Dedicated Server) 전환 고려 |

- 방장이 Host로 서버 역할 겸임, 별도 중앙 서버 없음
- 방장 접속 종료 시 세션 종료
- Mirror의 SyncVar / Command / ClientRpc 패턴으로 스탯·인벤토리·좀비 AI 동기화
- 출시 단계에서 Host / 전용 서버 선택 옵션 제공 예정
